## Что пошло не так (Troubleshooting)
В ходе выполнения лабораторной работы возникли сложности при сбросе пароля root (Задание 6). При попытке сброса через `init=/bin/bash` система выдавала ошибку `Cannot open access to console, the root account is locked`, что связано с блокировкой root-аккаунта в Fedora и защитой SELinux. Проблема была успешно решена путем добавления параметра `selinux=0`, отключения SELinux на время загрузки, а также принудительной установки пароля через команду `echo "admin:123456" | chpasswd`. После выполнения команды `touch /.autorelabel` и перезагрузки вход в систему был успешно восстановлен.
